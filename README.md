# ReflectionLeakEngine

강시현은 어린 시절 힘들거나 슬픈 일이 있을 때마다 가족과 함께 돈까스를 먹었다.

돈까스는 위로의 음식이었다.

하지만 시간이 지나 어른이 된 그는 돈까스를 더 이상 편하게 먹을 수 없게 된다. 위로받았던 기억과 상처받았던 기억이 분리되지 않은 채 남아 있었기 때문이다.

ReflectionLeakEngine은 이러한 감정의 잔존과 축적을 코드 구조로 표현하기 위한 실험적 프로젝트이다.

프로그램은 특정 데이터를 입력받아 내부에 저장한다. 저장된 정보는 쉽게 사라지지 않으며, 새로운 정보가 들어올수록 시스템은 점점 더 많은 부담을 안게 된다.

이 구조는 단순한 기술적 메모리 누수가 아니라, 인간이 경험과 감정을 완전히 삭제하지 못한 채 살아가는 상태를 모티브로 한다.

어떤 기억은 사라지지 않는다.

종료 전까지.

어쩌면 종료 후에도.
